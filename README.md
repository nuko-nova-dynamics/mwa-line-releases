# MWA Line — Releases

Download and update channel for the MWA Line desktop app, the Line on macOS, Windows and Linux. The app checks this repository's releases for updates.

- **macOS:** download the `.dmg` for your Mac (`arm64` for Apple silicon, `x64` for Intel), open it, and drag MWA Line to Applications.
- **Windows:** download the `.exe` and run it.
- **Linux (Arch, Omarchy):** download the `.pacman` file and install it with `sudo pacman -U mwa-line-<version>-x64.pacman`.
- **Linux (other):** download the `.AppImage`, make it executable (`chmod +x`), and run it.
- **Updates:** the installed app downloads new versions itself and installs them when you quit it. The `.zip`, `.blockmap` and `latest*.yml` files exist for that.
